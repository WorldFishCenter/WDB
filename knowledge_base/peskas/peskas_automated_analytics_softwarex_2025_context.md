# Context: peskas_automated_analytics_softwarex_2025.pdf

## Summary
Peer-reviewed software publication (SoftwareX 29, 2025, art. 102028) describing
**Peskas**, a low-cost, open-source, near-real-time analytics workflow for small-scale,
data-deficient fisheries. It provides a template pipeline from data ingestion through
analysis to a decision dashboard, adaptable to different country contexts and needs.

## Key concepts / entities
- Near-real-time analytics; small-scale fisheries (≈90% of global fisheries employment, >40% of catch)
- End-to-end workflow: ingestion → analysis → decision dashboard
- Stock assessment; IUU (illegal, unreported, unregulated) fishing monitoring
- Low-cost / open-source template adaptable across contexts; Least Developed Countries; food & nutrition security
- Authors: Lorenzo Longobardi, Villiam Sozinho, Hamza Altarturi, E. Fernando Cagua, Alexander Tilley (WorldFish, Penang; School of Global Development, University of East Anglia)
