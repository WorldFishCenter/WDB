# Peskas

## Summary

This peer-reviewed publication in SoftwareX (Volume 29, 2025) describes Peskas, an open-source software system developed by WorldFish and the University of East Anglia for automated analytics and decision support in small-scale, data-deficient fisheries. The article establishes Peskas as a low-cost, template-based workflow that ingests, processes, and visualises fishery data in near-real-time, addressing logistical, financial, and capacity constraints that hinder data collection and interpretation in small-scale fisheries. It includes metadata linking to the system’s code repositories and a reproducible capsule.

## Key concepts

- **Peskas**: An open-source system produced by researchers at WorldFish and the University of East Anglia (authors: Lorenzo Longobardi, Villiam Sozinho, Hamza Altarturi, E. Fernando Cagua, Alexander Tilley) that provides a template workflow for automated ingestion, analysis, and visualisation of small-scale fisheries data via a decision dashboard.
- **Near-real-time analytics**: Peskas enables near-real-time processing of fishery data to support stock assessment and detection of illegal, unreported, and unregulated (IUU) fishing.
- **Decision dashboard**: The system includes a dashboard component (peskas.timor.portal) that presents analysis results, built on top of the data pipeline (peskas.timor.data.pipeline).
- **Template workflow**: Peskas provides an adaptable ingestion and analysis workflow that can be customised to different contexts and needs, with the Timor-Leste case serving as an example.
- **Code repositories and reproducibility**: The article links to two GitHub repositories — `peskas.timor.portal` and `peskas.timor.data.pipeline` — and their corresponding Zenodo capsules (DOI 10.5281/zenodo.10906764 and 10.5281/zenodo.10906697 respectively), ensuring reproducibility of the software.
