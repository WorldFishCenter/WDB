# Peskas: Automated analytics for small-scale, data-deficient fisheries
## Summary
This document is a publication in SoftwareX that introduces Peskas, a low-cost solution for automated analytics in small-scale, data-deficient fisheries. It establishes Peskas as a template workflow for data ingestion and analysis, culminating in a decision dashboard.
## Key concepts
Peskas provides automated analytics for small-scale, data-deficient fisheries. Peskas addresses challenges in gathering and interpreting data in small-scale fisheries. Peskas offers a template workflow for data ingestion and analysis. Peskas produces a decision dashboard. The Peskas code is available in two versions: `peskas.timor.portal v1.0.0` and `peskas.timor.data.pipeline v3.1.0`. The Peskas code is licensed under the Apache License.
