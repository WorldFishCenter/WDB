# Peskas: Automated Analytics for Small-Scale, Data-Deficient Fisheries
## Summary
This SoftwareX journal publication describes Peskas, a low-cost solution designed to provide automated analytics for small-scale, data-deficient fisheries. It establishes a template workflow for data ingestion and analysis, culminating in a decision dashboard, which can be adapted to various contexts and needs.

## Key concepts
*   **Peskas:** A low-cost solution for automated analytics in small-scale, data-deficient fisheries, designed to address logistical, financial, and capacity challenges in data gathering and interpretation.
*   **Peskas workflow:** Provides a template for data ingestion and analysis, which culminates in a decision dashboard.
*   **Peskas components:** The system includes `peskas.timor.portal` (v1.0.0) and `peskas.timor.data.pipeline` (v3.1.0).
*   **Authors:** Lorenzo Longobardi, Villiam Sozinho, Hamza Altarturi, E. Fernando Cagua, and Alexander Tilley are the authors of this publication.
